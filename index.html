About Me

我是莊孔禎，一個對世界充滿好奇心、熱衷於從日常中挖掘驚喜的人。

我相信細微的「觀察」是所有創意的起點。我天生喜歡觀察身邊的人事物，這讓我具備了敏銳的洞察力，也常讓我產生與眾不同的新奇想法。對我來說，生活不該是一成不變的，我享受每天「尋找好玩事物」的過程，並將這些靈感轉化為不一樣的視角。

我非常喜歡與人相處，享受交流中的火花。具備敏捷的反應能力，讓我能快速理解他人並給予暖心的回應。我喜歡挑戰，更喜歡在挑戰中找到樂趣，致力於用最靈活的思維，為世界帶來一點點不一樣。

畢業專題｜美惠姐講古：潤滑油顧問

2025 - 2026 | 產學合作專題
專案目標： 與傳統產業「隆福行」合作，針對知識斷層痛點，建構高可靠、即時互動的 AI 知識管理系統，實現專業技術的數位轉型與永續傳承。
核心技術： n8n, Ollama (LLM), Pinecone (向量資料庫), Docker, Line Bot API

工作內容：

  • RAG 架構開發：負責 n8n 自動化工作流，整合 Ollama 與 Pinecone 實現檢索增強生成架構。
  • 系統部署優化：運用 Docker 容器化技術及 Line Bot 部署，確保開發與生產環境的一致性與隔離性。
  • 權限系統設計：實作 RBAC (角色存取控制)，達成管理員與一般使用者之功能隔離。
  • 需求分析與對接：實地與隆福行經理交流，將實務需求轉化為系統設計規格。
學習成果： 掌握容器化部署技術提升系統穩定性，並透過權限控管實作，建立數據隱私保護與防範越權存取的思維。
